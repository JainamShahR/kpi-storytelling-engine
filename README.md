# KPI Storytelling Engine

Detects unusual movements in daily business KPIs, explains **where** the change
came from (region / product / channel), retrieves supporting business notes,
and writes a short narrative that is automatically checked against the computed
facts.

> **Status: work in progress.** The project is being built phase by phase.
> Phase 1 (project skeleton, configuration, CI) is complete. The full README -
> architecture diagram, installation, measured evaluation results and design
> decisions - is written in Phase 15.

## Quick start (current state)

```bash
python3.11 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # optional: all values have defaults

python -m src.config               # print the validated configuration
pytest                             # run the test suite
```

## Data disclaimer

All KPI data and business notes in this repository are **synthetic** and
generated by `generate_data.py`. They do not represent any real company.
